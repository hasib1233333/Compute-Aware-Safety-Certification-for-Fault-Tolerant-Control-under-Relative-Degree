Title
Linking Computational Budget to Certified Safety Margins for Robot Fault Tolerant Control
Abstract
Active fault-tolerant control usually treats detection latency as something to measure after the fact, not something derived from available computation. We introduce Budgeted Fault-Tolerant Control (BFTC), which treats the fault detector as an anytime estimator and derives a certificate linking compute budget, fault severity, and the worst-case drop in safety margin before a fault estimate can be trusted. The certificate rests on the detector's covariance rather than its raw point estimate, since only the covariance shrinks predictably as compute increases. On a double-integrator testbed, BFTC produces zero observed violations across every tested budget within the moderate fault-severity range (a 4% violation rate appears only at the extreme tested bound, delta_max = 0.85), outperforming a conservative passive baseline (paired effect size dz = 2.9-10.9) and two active baselines on safety (McNemar p < 0.001). Two further, independent testbeds - a PyBullet manipulator and a from-scratch pendulum - reproduce this result with zero violations in 40 trials each, and a multi-actuator scalability study (m = 1 to 16) confirms the predicted cost of scale. Against representative adaptive and robust-MPC baselines, a naive adaptive controller proves unsafe (70% violations), while robust MPC matches BFTC's safety record at five times the compute cost. The closest prior concept, Fault-Tolerance Latency from real-time computing, only checks whether recovery finishes before a deadline; this work derives a probabilistic bound indexed to compute budget instead. A negative result - no relative-degree-one barrier function correctly captures inverted-pendulum safety - marks a boundary for where the theory applies. Every result here comes from simulation; hardware validation is future work.
Keywords
fault-tolerant control, control barrier functions, safety-critical control, real-time systems, anytime algorithms
