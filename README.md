Title
Compute-Aware Safety Certification for Fault-Tolerant Control under Relative-Degree-One Safety Constraints

Abstract
Active fault-tolerant control (FTC) treats fault-detection latency as an assumed or empirically-reported quantity, not one derived from an explicit compute budget. We introduce Budgeted Fault-Tolerant Control (BFTC), which models the fault detector as an anytime estimator and proves a certificate relating compute budget, fault-severity bound, and worst-case safety-margin degradation before a fault estimate is trusted, built on a covariance-based, not point-estimate-based, confidence radius. On a hand-verifiable double-integrator testbed, BFTC achieves zero observed violations across every tested compute budget throughout the validated moderate fault-severity range (a 4% violation rate emerges only at the extreme tested bound, delta_max = 0.85) while dominating a conservative passive-FTC baseline on performance (paired effect size dz = 2.9-10.9) and two active-FTC baselines on safety (McNemar p < 0.001). Two further, structurally independent testbeds - a real PyBullet 7-DOF manipulator and a from-scratch simple pendulum - reproduce this result (0/40 violations each), and a multi-actuator scalability study (m = 1 to 16) confirms a proven cost-of-scale prediction. Against representative adaptive and robust-MPC baselines, a naive adaptive design proves unsafe (70% violations) while robust MPC matches BFTC's safety and slightly exceeds its performance at five times the compute cost. The closest prior concept, Fault-Tolerance Latency from real-time computing, only checks whether recovery completes before a fixed deadline; we derive a compute-indexed, probabilistic bound instead. A negative result - no relative-degree-one control barrier function correctly captures inverted-pendulum safety - establishes an explicit scope boundary for the theory. All results are simulation-based; physical hardware validation remains future work.

Keywords
fault-tolerant control; control barrier functions; safety-critical control; real-time systems; anytime algorithms
